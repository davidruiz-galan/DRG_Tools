# DRG Tools release checklist

- [ ] Update `VERSION`.
- [ ] Update `python/drg_tools/config.py`.
- [ ] Update `CHANGELOG.md`.
- [ ] Compile-check all Python files.
- [ ] Test Nuke launch with a clean `.nuke` profile or clean plugin path.
- [ ] Test NodeInfo Alt + MMB.
- [ ] Test NodeInfo persistent inspector.
- [ ] Test Start / Reset / Stop Performance Timers.
- [ ] Create every new gizmo from the DRG Nodes toolbar.
- [ ] Test gizmo knobs and channels.
- [ ] Check icons and About dialogs.
- [ ] Zip the top-level `DRG_Tools` folder.
- [ ] Tag the release in Git when publishing publicly.

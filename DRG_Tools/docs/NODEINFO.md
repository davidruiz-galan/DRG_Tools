# NodeInfo 1.3.0

NodeInfo is the Python/UI component of DRG Tools.

## Quick inspector
Hold **Alt + Middle Mouse Button** over a node. The popup disappears as soon as Alt or the middle mouse button is released.

## Persistent inspector
Select a node and press **Alt + Shift + I**. This mode includes Refresh, Reset timers, Plain Text, Copy and Close.

## Profiling menu
`DRG > NodeInfo` contains:
- Inspect Selected Node
- Start Performance Timers
- Reset Performance Timers
- Stop Performance Timers / Restore Nodes
- Advanced > Show Nuke Native Profiler
- Advanced > Hide Nuke Native Profiler
- Advanced > Reset Profiling Data
- About NodeInfo

NodeInfo does not automatically start Nuke's native performance timers when Alt + MMB is used.

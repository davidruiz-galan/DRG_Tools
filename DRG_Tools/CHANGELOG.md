# Changelog

## DRG Tools 0.1.0 — 2026-09-15

### Added
- Initial unified DRG Tools ecosystem.
- NodeInfo 1.3.0 integrated as `drg_tools.nodeinfo`.
- DRG top menu with NodeInfo profiling controls and About dialog.
- `Stop Performance Timers / Restore Nodes` command.
- Directional Dilate 1.0.0 gizmo.
- Nodes toolbar: `DRG Tools > Filter > Directional Dilate`.
- Central metadata, icon paths and tool creation helpers.
- User and developer documentation.
